::analogy
A loop is a tireless night shift working through the stack.
::

Some jobs aren't one big task, they're the same small task done a hundred times: tag every invoice,
draft a reply to each review, rename all the files. A [[loop]] is when you hand that stack to the AI
and say "do this one step to every item," like leaving a night shift to work through the pile while
you sleep.

::figure id=night-shift label="Fig. 8 — The night shift" caption="One step, repeated down the whole stack, done pile rising."

You define the single step once, clearly, and the loop applies it down the line. The power isn't
cleverness, it's patience at scale: the hundredth item gets the same care as the first, without you
sitting there for all hundred.

::note
Spot the pattern in your own week: any "and now the same thing again, and again" is a loop waiting to be handed off.
::
