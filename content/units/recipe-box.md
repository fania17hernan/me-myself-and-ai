You've written a great prompt before, gotten it just right, then lost it in the scroll and rebuilt it
from memory the next week. A [[template]] fixes that. Think of it as a recipe box: the good version,
written once on a card, filed where you can grab it.

::figure id=recipe-box label="Fig. 3 — The box" caption="Write it once. Pull the card instead of retyping."

## 1 · Notice what you retype

The weekly-summary prompt. The "rewrite this in my tone" prompt. The listing-description prompt.
Anything you type more than twice is a recipe waiting to be saved.

## 2 · Save the good version, not the first draft

Get it working, then save _that_ one, the wording that reliably produces what you want. Most tools have
a saved-prompts or library feature; a plain note also works.

## 3 · Leave a blank to fill in

The best recipes have one gap: "Summarize [PASTE NOTES] into five bullets for my team." Pull the card,
drop in this week's notes, done. That is a workflow you can hand off, even to yourself on a busy day.

::note
Start your box this week with one card: the prompt you already reach for most.
::
