::analogy
Si el chat es un pizarrón, la memoria es el cuaderno.
::

Ya conociste el pizarrón: todo en una conversación, borrado al terminar. Por eso un chat nuevo no
te conoce. La [[memory]] es el cuadernito que la IA guarda _junto_ al pizarrón, donde anota unos cuantos
datos duraderos sobre ti para llevarlos a la siguiente conversación.

::figure id=notebook label="Fig. 2 — El cuaderno" caption="El pizarrón se borra. El cuaderno guarda las notas."

Así puede recordar que diriges un equipo de ocho personas, que prefieres viñetas y que planeas una
mudanza en marzo, sin que se lo vuelvas a explicar. El pizarrón sigue siendo donde ocurre el
pensamiento cada vez. El cuaderno solo hace que no empieces cada chat como un desconocido.

::note
Puedes leer y editar el cuaderno. Abre los ajustes de memoria para ver lo que anotó y tacha lo que prefieras que olvide.
::

"El pizarrón se borra. El cuaderno guarda unas notas para la próxima."
